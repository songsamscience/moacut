## 검증 못 한 것

- 기본 소리를 귀로 듣기(숫자로만 확인 — 외부 효과음 이름은 Kenney 파일 이름 기준), 외부 곡의 목소리 유무는 페이지 설명 기준.
- 모션: 1080p · 4K 출력(720p 만 비교, 4K 전체 화면 색종이 메모리), 9:16 · 1:1, 화살표 · 강조 · 카운트다운 · 이름표의 출력 화소 비교. 상세를 안 연 채 정답/오답 카드를 바로 추가하면서 효과음 받기가 900 ms 를 넘으면 실행 취소가 두 단계가 됨.
- 소리: 반복 이음매 미리보기를 귀로 듣기(자리 바꿀 때 ≈ 16 ms), 녹음 · AI 음성 반복, 2× · 4× 재생 중 반복, 아주 긴 반복(10분 · 150번)의 시간 · 메모리, 반복 항목 가장자리 끌기 화면 시험, 클리핑 어림 정확도(1건만).
- 자료실 화면: 사용 구간 손잡이 마우스 끌기 · 파형 눌러 탐색, 확대 100 % · 200 % 화면, 출처 「복사」(클립보드 — 내려받기만 확인), 이미지 임시 배치의 미리보기 화소, 배포 빌드에서 오프라인 자료실, 사파리 · 파이어폭스 · 터치, 밝은 화면, 900 px 이하 좁은 화면(820 px 한 장만).
