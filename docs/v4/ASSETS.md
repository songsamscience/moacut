## 등록 기준(요구사항 §2)
- **직접 제작**: 이 저장소의 코드로 만든 것만. 소리는 `tools/library/make-self-assets.mjs`(수식 합성, 고정 씨앗 잡음 — 외부 음원 · 샘플 없음), 그림은 `tools/library/svg/*.svg`(손으로 쓴 SVG, `<text>` · 글꼴 · 외부 그림 없음)를 `tools/library/render-svg.mjs`(헤드리스 Chrome)로 PNG 로. 라이선스 「직접 제작(CC0 1.0)」.
- **외부 CC0**: 사이트 전체가 아니라 **개별 팩 · 곡 페이지**에서 CC0 를 확인한 것만. 압축 안에 License.txt · readme 가 있으면 그것도 확인. 여러 라이선스를 함께 적은 것, 다른 사람 샘플 · 루프 · 사운드폰트 · 리믹스 언급, 목소리, 권리 불명 녹음, 대리 등록, 라이선스가 엇갈리는 기록이 있는 것은 넣지 않는다.
- 확인 못 한 것은 목록에 넣지 않는다(넣더라도 `verified: null` → `isPublishable` 이 걸러 화면에 안 보임).
- Pixabay · Mixkit · Freesound 등은 쓰지 않았다(§2).

## 소재 추가 방법
1. **파일 준비**
   - 직접 만든 소리: `tools/library/make-self-assets.mjs` 의 `SOUNDS`(효과음) 또는 `MUSIC`(배경음)에 함수를 더하고 `node tools/library/make-self-assets.mjs <id>` → `public/library/sfx/<id>.wav` · `bgm/<id>.mp3`. 표에 찍히는 최고 · RMS · 반복 경계 숫자를 확인.
   - 직접 그린 그림: `tools/library/svg/<id>.svg`(글꼴 · 외부 그림 없이) → `node tools/library/render-svg.mjs <id>` → `images/<id>.png` + `thumbs/<id>.png`.
   - 외부 CC0: ① 개별 팩 · 곡 페이지에서 라이선스 칸을 확인(여러 라이선스 · 샘플 · 리믹스 · 목소리 · 인물 · 상표가 있으면 넣지 않음) ② 내려받은 압축은 새 빈 폴더에 풀고 License.txt 를 확인(안의 프로그램은 실행하지 않음) ③ `tools/library/import-external.mjs` 의 `PACKS` · `LIST` 에 한 줄 더하고 `node tools/library/import-external.mjs <내려받은 폴더> <id>`. 효과음은 WAV · MP3, 배경음은 MP3 128~160 kbps, 그림은 PNG 만(OGG 는 사파리 문제로 안 씀).
2. **목록 항목 쓰기** — 해당 `public/library/catalog/{images,sfx,bgm}.json` 의 `items` 에 `LibItem`(`src/library/types.ts`) 형식으로 한 개 추가:
   `id`(바꾸지 말 것, `img-` · `sfx-` · `bgm-` 머리) · `kind` · `name` · `nameEn` · `desc` · `tags`(한글: 「뿅 · 딩동 · 박수 · 우주 · 실험 · 차분한 · 화살표」처럼 찾을 말) · `tagsEn` · `mood`(밝은 · 차분한 · 신나는 · 긴장감 · 신비로운 · 웃긴) · `use`(과학 실험 · 발표 · 퀴즈 · 학교 행사) · `file` · `thumb`(그림) · `loopable`(반복 곡) · `author` · `authorUrl` · `source`(외부 = 원본 페이지 주소, 직접 제작 = 생성 스크립트 · SVG 경로) · `license {name, url}` · `commercial` · `redistribute` · `verified {date, how}`(무엇을 어디서 확인했는지 한 줄 — 확인 못 했으면 `null`) · `credit {text, required}`.
   길이 · 크기 · 파형(`duration` · `width` · `height` · `bytes` · `peaks`)은 쓰지 않아도 된다.
3. **채우기 · 검사** — `node tools/library/build-catalog.mjs` : 파일에서 길이 · 크기 · 파형을 채우고 필수 칸 · id 중복 · 파일 존재 · 형식 · `isPublishable` · 30 MB 예산을 검사한다. 「문제」가 하나라도 있으면 종료 코드 1. `--md` 를 붙이면 이 문서의 표를 다시 만든다.
4. **앱에서 확인** — `npx vite --port 8884 --strictPort` → 자료실에서 이름 · 태그로 찾기 → 미리보기/미리듣기 → 추가 → 출처 목록에 제작자 · 라이선스가 맞게 나오는지 본다.
5. 이 문서 「외부 소재를 확인한 방법」(외부일 때) · `LICENSES.md` 「기본 소재」 표를 고치고 커밋.

## 확인 기록(2026-10-10)
- `node tools/library/build-catalog.mjs --md` → 119개 · 공개 119 · 문제 0 · 주의 0. `public/library` 전체 **18.37 MB / 30 MB**(images 2.38 · thumbs 0.15 · sfx 6.08 · bgm 9.61 · catalog 0.15 MB).
- 개발 서버(`npx vite --port 8884`)에서 index.json → 파트 5개 → 파일 · 썸네일 160개 모두 HTTP 200 · 크기 일치(image/png 82 · audio/wav 64 · audio/mpeg 14).
- 헤드리스 Chrome 에서 119개 모두 해독 성공(그림 createImageBitmap 크기 일치, 소리 decodeAudioData 길이 일치). 반복 배경음 13곡은 Chrome 이 해독한 표본 수가 원래 반복 길이와 같음(MP3 앞뒤 패딩이 잘림).
- 직접 제작 소리 수치(최고 · RMS · 무게중심 · 반복 경계)와 그림 확인(헤드리스 Chrome 그림 ↔ librsvg 그림 비교, 깨진 그림 0)은 `docs/v4/IMPL_LOG_assets.md`.
