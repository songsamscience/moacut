# 모아컷 UI · 디자인 검토 — 다른 편집기와 견주어 (Fable, 2026-10-10)

검토 대상: `main` bebcf68 (v0.5.2), 개발 서버 :8871. 시험 미디어(`tests/media`) 4 클립 + 배경음악 + 자막 3개를 넣고 1440×900 을 기본으로 1920×1080 · 1280×720 · 1024×768 · 375 폭에서 어두운 · 밝은 화면을 모두 찍어 봤어요(캡처 86장 중 근거가 되는 14장은 `docs/v3.5/shots/`). 코드는 `src/ui/keymap.ts` · `Timeline.tsx` · `Stage.tsx` · `Library.tsx` · `styles/*.css` 를 기능 유무 확인용으로만 훑었어요(설계 · 자료구조는 Opus 몫).

견준 편집기: **CapCut(데스크톱) · VLLO · Clipchamp**(같은 초보 대상), **파이널컷 · 프리미어 · 다빈치 리졸브**(관습의 기준). 「초보 교사가 10분 안에 수업 영상을 올린다」는 모아컷의 목표(IDEAS_FABLE §1)와 「하지 말 것」(§5: 유료 API 금지 · 전문가용 타임라인 금지 · 미리보기 = 출력)은 그대로 전제했어요.

## 0. 한눈에

**인상**: 색 · 글꼴 · 카드 · 해요체 문구 · 분류 탭 · 삭제 확인 창 · 내보내기 창 등 **「보이는 디자인」은 이미 상용 편집기 수준**이에요. 뒤처진 건 디자인이 아니라 **편집기라면 당연히 있는 「손에 익은 조작」** — 우클릭 메뉴 · 휠 확대 · J/K/L · 입점/출점 · 호버 툴팁 — 과 **화면 배분**(타임라인이 너무 낮고 보관함 카드가 너무 큼)이에요.

|---|---|---|

## 1. 잘 된 점(지킬 것)

- **디자인 시스템** — 차콜 + 분홍 강조 + 18 px 카드, 어두운 · 밝은 두 테마 대비 모두 양호. 타임라인 줄 색(영상 남색 · 자막 황토 · 배경음악 녹색 · 화면 위 보라)이 구분돼요.
- **속성 칸 분류 탭**(v3.1) — 긴 패널을 스크롤 대신 탭으로. 바뀐 값에 점 표시, 마지막 탭 기억. CapCut 의 오른쪽 탭과 같은 관습이라 익숙해요.
- **클립 경계 「+」 메뉴**(`08-boundary-plus-menu.jpg`) — 「n번째 · m번째 클립 사이 / 화면 전환 넣기 / 끼워 넣기」. 문맥을 글로 보여 주는 점이 CapCut 보다 친절해요.
- **삭제 확인 창**(`10-cascade-delete.jpg`) — 함께 지워질 자막 · 화면 위 · 모자이크를 목록으로, 「⌘Z 한 번으로 되돌릴 수 있어요」. 프리미어 · 파이널컷엔 없는 배려.
- **내보내기 창** — 해상도 타일에 픽셀 · 배지, 실제 진행률(단계 · 클립 · 경과), 머리 막대 알약. 「해상도를 몰래 낮추지 않음」 원칙.
- **모자이크 상자 위 도구 막대**, **PIP 빠른 위치 9칸**, **AI 보이스 창 하나** — 초보가 헤매지 않게 한 곳에 모은 구조.
- **연결 편집 · 마커 · 스냅 · 원본 보기 I/O** — 파이널컷 식 연결 클립을 「연결 줄기」로 그려 이해시키는 방식이 좋아요.
