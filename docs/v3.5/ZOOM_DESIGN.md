# 타임라인 확대 · 축소 설계(v3.5 트랙 A · P0-7)

Fable 2026-10-10 · 구현 Opus. 범위 = `Timeline.tsx` 확대 · 눈금자 · 휠 · 개요 막대(A 높이 · 세로, C 입점/출점 · J/K/L, B 메뉴는 안 건드려요). 확대는 **보기 상태**라 미리보기 · 내보내기와 무관, 프로젝트에 저장 안 함(열면 화면에 맞추기).

## 1. 기준점(확대해도 그 자리에 머무는 시각)
| 조작 | 기준점 |
|---|---|
| `+` `−` 키 · 단추 | 재생선이 보이면 **재생선**, 아니면 **보이는 범위 가운데** |
| 슬라이더 | 같되 **누른 순간**의 기준점을 끌기 끝까지 유지 |
| Ctrl/⌘+휠 · 핀치 | **커서 아래 시각** |
| 터치 두 손가락 | 두 손가락 가운데 |
| 개요 막대 끝 끌기 | 반대쪽 끝 |
| ⇧Z 화면에 맞추기 | scrollLeft 0 |
| Z 고른 것에 맞추기 | 고른 것 가운데 |

식 `scrollLeft' = t기준 × 배율' − x기준`(트랙 영역 안 px), 0~최대로 잘라 **배율과 같은 프레임**에 적용. 애니메이션 없음(휠 · 핀치는 이벤트마다 조금씩이라 저절로 매끄러움).

## 2. 휠 · 트랙패드(`.timeline__scroll` 위에서만)
| 입력 | 하는 일 | 양 |
|---|---|---|
| 휠 | 세로 넘기기(A · 브라우저 기본) | — |
| Shift+휠 | 가로 넘기기 | deltaY 그대로(줄 단위 ×40 px, 페이지 단위 = 보이는 폭 ×0.8) |
| 트랙패드 옆으로(deltaX) | 가로 넘기기 | 1:1 |
| Ctrl/⌘+휠 · Alt+휠 | 확대(커서 기준) | 배율 × 1.25^(−deltaY/100): 한 칸 = 단추 한 번, 이벤트당 ×½~×2 제한 |
| 핀치(크롬 = ctrlKey 붙은 작은 deltaY) | 같음 | 같은 식이라 연속 |

React `onWheel` 은 passive → 네이티브 리스너(`passive:false`)로 수식어 휠만 `preventDefault`. 프레임마다 모아 적용(rAF). 글 입력칸 포커스면 키 무시.

## 3. 배율 범위(px/초)
| 끝 | 값 | 근거 |
|---|---|---|
| 최대 | **600** | 1프레임 = 20 px(손으로 잡힘), 한 화면 ≈ 1.8초, 저장소 상한과 같음 |
| 최소 | **max(0.1, 맞추기 배율)** | 축소 끝 = 전체가 한 화면. 0.1 = 1080 px 에 3시간 |
| 기본 | 60 | 지금과 같음 |

모든 조작이 같은 범위, 끝이면 `+`/`−` 비활성 · 키 무시. 슬라이더 = 최소~600 로그(0~100) → **왼쪽 끝 = 전체 보임**. 창 폭 바뀌면 다시 자름.

## 4. 눈금자
큰 눈금(라벨) = px ≥ 70 인 가장 작은 후보(초): 0.1 · 0.2 · 0.5 · 1 · 2 · 5 · 10 · 20 · 30 · 60 · 120 · 300 · 600 · 1200 · 1800 · 3600.
작은 눈금(라벨 없음, px ≥ 8 일 때만) 짝: 0.1 · 0.2→1프레임, 0.5→0.1, 1→0.2, 2→0.5, 5→1, 10→2, 20→5, 30 · 60→10, 120→30, 300→60, 600→120, 1200 · 1800→300, 3600→600.
라벨: 간격 1초 이상 `mm:ss`, 1초 미만 `mm:ss.cc`(00:02.20), 총 60분 이상 `h:mm:ss`. 프레임 라벨 없음. 큰 눈금 8 px `--ruler-ink`, 작은 4 px `--border-hover`, 라벨 11 px.

## 5. 고른 것에 맞추기(새 조작)
- 키 **`Z`** · [⤢] 옆 단추(lucide `Focus`, 「고른 것에 맞추기」).
- 대상: 고른 블록들의 전체 범위 → 없으면 입점/출점 구간(C) → 그것도 없으면 비활성 · 키 무시.
- 양쪽 여백 8 %(최소 24 px), 가운데 정렬, §3 범위로 자름.
- 결과 그대로일 때 다시 `Z` → 이전 배율 · scrollLeft 복원(라벨 「이전 배율로」, `aria-pressed`). 다른 확대 · 넘기기가 끼면 기록 지움.

## 6. 개요 막대 — 넣어요
| | 내용 |
|---|---|
| 자리 | 타임라인 **맨 아래**(세로 스크롤 밖), 줄 머리 폭만큼 들여 트랙과 정렬. 가로 스크롤바는 숨김 |
| 높이 | 14 px(터치 22), 위아래 여백 2 px |
| 그림 | 바탕 `--bg-soft`, 영상 띠 `--clip-video-line` 60 %, 마커 1 px `--marker`, 재생선 1 px `--playhead` |
| 창 | 채움 `--accent-soft`, 테두리 1 px `--accent`(호버 `--accent-hover`), 손잡이 8 px(닿는 영역 16 · 터치 24), 최소 폭 24 px |
| 조작 | 가운데 끌기 = 넘기기 · 끝 끌기 = 확대(반대 끝 고정) · 창 밖 클릭 = 그 자리로 · 두 번 클릭 = 화면에 맞추기 |
| 전체 보일 때 | 창 꽉 참 · 손잡이 숨김(막대는 남김) |

## 7. 줄 높이 — 이번 판 안 넣어요
높이 끌기 · 자동(A)으로 충분, 초보에게 확대 축 둘은 혼란. 다음 판 후보: 우클릭 메뉴(B) 「줄 높이 ▸ 작게 · 보통 · 크게」.

## 8. 배율 보여 주기
슬라이더 툴팁 · `aria-valuetext` = **「보이는 범위 약 40초」**, 키 · 휠 · 핀치 뒤엔 같은 칩(`.zoom__readout`)을 슬라이더 위에 800 ms. 반올림: 10초 미만 0.5초, 60초 미만 정수 초, 「약 2분 30초」 「약 1시간 5분」. 최소면 「전체가 보여요」.

## 9. 터치(375 px)
`.timeline__scroll` 에 `touch-action: pan-x pan-y`(페이지 확대 막기, 한 손가락 넘기기는 기본). 두 손가락 = 포인터 2개 거리 비율로 확대(가운데 기준) + 넘기기(Safari 는 `gesturechange`). 600 px 아래면 슬라이더 숨김, 개요 22 px.

## 10. 성능 원칙
보이는 범위 ±1화면만 그리기(클립 · 눈금 · 썸네일 · 파형), 썸네일은 재추출 없이 캐시 띠에서 샘플, 휠 rAF 합치기, 레이아웃 읽기 프레임당 1회. 목표: 60분 프로젝트 Ctrl+휠 프레임 ≤ 16 ms.

## 11. 단추 짝 · 도움말 표(「보기」 묶음, 이 순서)
| 하는 일 | 윈도우 | 맥 | 짝 단추 |

| 타임라인을 화면에 맞추기 | Shift+Z | ⇧Z | [⤢] · 개요 두 번 클릭 |
