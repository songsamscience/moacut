## 2. 고른 방법
- 같은 성별 프리셋 1·2·3개 양수 섞기 224개(0.15~0.85) × 탐색 문장 8개 → 지표: 끝 올림 비율, 쉼표 쉼, 사람 낭독과 음절 F0 곡선 상관, GOP, 나이·성별(audeering), F0 · 조음 속도 · 에너지, ECAPA 임베딩.
- 같은 성별 5개를 **임베딩 코사인 ≤ 0.83 + 음높이/에너지 차**로 함께 고름 → 측정값 순서로 이름 · 설명을 붙임(정직성 규칙).
- 최종 10개는 시험 글 A(8문장 × 씨앗 2) · FLEURS 12문장 · 긴 글 C · 읽기 글 B로 다시 검증.

## 4. 6번 「밝고 발랄한 대학생 톤」 추가(v3.3, 2026-10-10)

사용자: 「학생 목소리의 남녀 밝은 목소리가 빠졌다 → 6번으로」, 「타입캐스트(→ Fish Audio)를 참고했어야」.

- **참고 목소리 측정**: 타입캐스트는 목소리 목록 · 미리 듣기가 로그인 뒤에만 열려 쓰지 못함. 사용자가 로그인한 Fish Audio 의 **공식(Fish Official) 한국어 목소리 12개** 공개 미리 듣기 샘플(크레딧 안 씀, 사용자 승인 뒤 1.5 MB 받음, `moacut-voice-lab/refs/fish_official/`, 앱에는 안 넣음)을 재서 **수치만** 기준으로 씀(음색 복제 없음).
  - 12개 모두 평서문 끝이 내려감(우리 고침 방향과 같음). 높낮이 폭이 큼(사분위 5~7 반음 · 범위 9~12 반음), 말이 빠름(조음 6.5~9.1 음절/초).
  - 나이 추정 모델은 「young」 표시 목소리도 28~38세로 잡음 → **추정 나이는 한국어에서 믿기 어려움**(상대 비교로만).
  - 밝은 청년 기준: 남 = 지훈 · 도윤 Doyun 평균(F0 130 Hz · 사분위 6.1 st · 범위 11.0 st · 조음 7.7), 여 = 서윤 · Yuna 평균(225 Hz · 6.7 st · 11.6 st · 7.0).
- **남성 6** = M4 .6 · F1 .2 · F2 .2, 빠르기 1.07 → F0 130 Hz · 사분위 6.7 st · 조음 7.0(기준과 거의 같음), 추정 나이 20(가장 젊음), 끝 올림 0 %, 쉼표 쉼 74 %, 다른 남성과 임베딩 코사인 ≤ 0.80.
- **여성 6** = F2 .75 · F1 .2 · F4 .15 · F3 −0.1(dp 는 양수만 정규화), 빠르기 1.0 → 218 Hz · 사분위 5.0 st · 조음 6.9, 추정 나이 23.5(여성 중 가장 젊은 쪽), 끝 올림 24 %(옛 대학생 여 76 %), 쉼표 쉼 84 %.
  - **한계**: 공개 프리셋에서 밝고 젊은 여성 음색은 F2 하나뿐이라 여성 4(F2)와 임베딩 코사인 0.96 — 비슷하게 들릴 수 있음. Fish 기준(높낮이 폭 6.7 st)에 가장 가까운 것도 여성 4(6.2 st)였고, 외삽 8가지로도 넘지 못함.
- 화면: 목록 12개(두 열 6줄), Fable 이 카드 높이 · 간격을 줄여 1366×768 한 화면 유지(`voice.css`).
