# 송쌤과학 모아컷 — 내 기기에서 처리하는 한국어 웹 영상 편집기

**배포 주소: https://songsamscience.github.io/moacut/** (GitHub Pages, 저장소 songsamscience/moacut — 빌드본만)

영상을 불러와 자르고 이어 붙이고, 한글 자막과 색감·배경음악을 넣은 뒤 **480p · 720p · 1080p MP4**(컴퓨터 사양이 되면 **2160p 4K**)로 저장하는 초보자용 편집기예요.
편집 · 인코딩 · 자동 자막(음성 인식) · 무음/장면 분석 · **AI 보이스(자막 읽어 주기)** 를 **모두 브라우저 안에서** 처리해요. 회원 가입 · 결제 · API 키 · 유료 서비스가 없고, 사용자의 영상 · 음성 · 자막을 어디에도 보내지 않아요.

왼쪽 **소재 자료실**에서 상업적으로 무료인 그림 · 효과음 · 배경음 · 모션그래픽(직접 제작 + 개별 페이지에서 CC0 를 확인한 것만)을 찾아 미리보고 바로 넣을 수 있어요.

- 흐름: **영상 불러오기 → 컷편집 → 자동 정리 → 자막·색감 → 자료실 소재 · 모션그래픽 → 전환·모자이크·리미터 → 내보내기**
- 기술: React 19 · TypeScript 5.9 · Vite 7 · ffmpeg.wasm 0.12(단일 스레드) · Transformers.js 3.8(Whisper, WebGPU/WASM) · zustand
- 디자인: 송쌤과학 도구 사이트 디자인 시스템 V1.1(작업대형) + 차콜·분홍·남색 조합(VLLO 웹사이트 인상을 참고해 새로 만든 색, 대비 70쌍 모두 4.5:1 이상 — `docs/UI_SPEC.md` §11)

## v4.1 새 기능 — 자막 무음 · 말소리 언어 · 번역 · 자막 표 (2026-10-15, 0.8.0)

- **무음 구간에 자막이 이어지지 않아요** — 배경음 · 잡음이 깔린 영상에서도 말소리만 찾아(Silero VAD) 받아쓰고, 말 없는 구간에는 자막을 두지 않아요. 한 문장을 둘로 나눌 때도 쉼 동안 앞 자막이 늘어나지 않아요.
- **말소리 언어 「자동」** — 말소리 조각마다 한국어 · 영어 · 일본어를 알아내 그 언어로 받아써요(한국어 내레이션 + 영어 인터뷰처럼 섞여 있어도).
- **자막 번역 · 보이는 언어** — 한국어 · English · 日本語 자막을 함께 만들고(크롬 기기 안 번역, 글은 기기 밖으로 나가지 않음), 원문 · 언어 하나 · 두 언어 함께 중에서 보일 언어를 골라요. 미리보기 · 영상 내보내기 · SRT 가 같은 언어를 따라요.
- **자막 표**(`⇧T`) — 모든 자막과 번역을 한 표에서 보고 칸에서 바로 고쳐요. 찾아 바꾸기(`Ctrl+F`)로 받아쓰기 오타(크래밸 → 크랜베리)를 한꺼번에 고치고, 원문이 바뀐 자막만 다시 번역해요. 바꾸기를 기억해 다음 자동 자막에도 적용할 수 있어요.
- **언어별 모두 저장(ZIP)** — `.ko.srt · .en.srt · .ja.srt`(+ WebVTT)를 한 번 눌러 ZIP 하나로(유튜브 자막 올리기용).
- **읽기 속도 검사** — 글자 수에 비해 너무 짧게 보이는 자막에 「빠름 · 너무 빠름」을 표시하고, 다음 자막 전까지 「끝 늘이기」로 맞춰요.

## v4 새 기능 — 소재 자료실 (2026-10-10, 0.7.0)

- **자료실 탭** — 왼쪽 패널이 「자료실」이 됐어요: 전체 · 이미지 · 효과음 · 배경음 · 모션그래픽 · 즐겨찾기 · 내 파일(예전 보관함). 기본 소재 **135개**(그림 41 · 효과음 64 · 배경음 14 · 모션그래픽 프리셋 16) — 직접 만든 것 + Kenney · OpenGameArt 의 **개별 팩 · 곡 페이지에서 CC0 를 확인한 것**만. 확인 근거가 없는 항목은 목록에 있어도 화면에 나오지 않아요. 목록 · 근거 · 소재 추가 방법은 `docs/v4/ASSETS.md`.
- **검색** — 이 앱에 들어 있는 자료실만 찾아요(인터넷 검색이 아니에요). 한글 · 영문 이름과 태그, 초성(`ㄷㄷ` → 딩동), 비슷한 말(동의어 33묶음), 거르기(종류 · 분위기 · 길이), 용도 모음(과학 실험 · 발표 · 퀴즈 · 학교 행사), 최근 사용 · 즐겨찾기, 결과가 없으면 관련 태그 제안 · 검색 초기화.
- **카드 · 상세** — 썸네일 또는 파형 · 길이 · 라이선스 배지 · 미리보기 · 추가 · 별. 상세에서 확대(맞춤 · 100 % · 200 %, 투명 바둑판) · 「현재 장면 위에 놓아 보기」(임시 배치 — 타임라인은 안 바뀜), 소리 재생 · 탐색 · **미리듣기 음량과 넣을 때 음량(dB) 따로** · 배경음 사용 구간 손잡이 · 구간 듣기, 제작자 · 원본 페이지 · 라이선스 원문 · 확인 날짜와 근거. 다른 소재를 들으면 앞의 것은 멈춰요.
- **넣기** — 「추가」 = 재생 위치, 또는 카드를 타임라인 「화면 위」 줄(그림 · 모션) · 소리 줄(효과음 · 배경음)에 끌어 놓기. 실행 취소 한 번으로 빠져요. 자료실 소리를 처음 넣으면 리미터가 꺼져 있을 때 켜 줘요(한 번 안내).
- **모션그래픽 7종(직접 만든 Canvas 템플릿)** — 움직이는 화살표 · 강조 원/사각형 · 카운트다운 · 이름표 · 정답/오답(효과음 켜기 · 끄기) · 제목 등장(페이드 · 슬라이드 · 확대) · 색종이(고정 씨앗). 속성 칸 「모션」 탭에서 문구 · 색 · 속도 · 길이 등을 바꾸면 바로 보이고, 미리보기와 출력이 **같은 그리기 함수**를 써서 재생 · 멈춤 · 탐색 · 내보내기에서 같은 시각에 같은 그림이에요.
- **배경음 편집** — 시작 시점 · 사용 구간 · 반복(경계 크로스페이드, 기본 0.03초) · 「선택 구간에 맞춰 반복 / 자르기」 · 페이드, 타임라인에 반복 경계 점선. **배경음 줄이기 구간**(내레이션 자리에서 배경음만 −dB)은 직접 정하거나 「말소리 후보로 채우기」(소리 크기로 찾은 후보 — 자동 감지가 아니라 후보이니 확인해 고쳐요). 여러 소리가 겹쳐 0 dBFS 를 넘길 것 같으면 내보내기 창에서 경고하고 「리미터 켜기」를 권해요(출력 뒤 실제 피크도 재요).
- **출처 · 라이선스 목록** — 자료실 바닥 「출처 목록」: 이 프로젝트에서 **쓰는** 소재의 제작자 · 원본 · 라이선스 · 출처 표기(필수/권장)를 보고 복사 · `.txt` 로 내려받아요. 내가 불러온 파일은 따로 「사용 권리는 직접 확인해 주세요」로 적고, 무료 인증 표시를 붙이지 않아요.
- **다시 열기 · 오프라인** — 프로젝트에는 자료실 소재의 id 만 저장되고, 다시 열면 자동으로 다시 받아요(「원본 다시 연결」 창엔 내 파일만). 한 번 받은 소재는 서비스 워커 캐시(`moacut-library-v1`)에 남아 인터넷 없이도 써요.
- **개인정보** — 자료실 바닥 · 저장 공간 창에 안내: 「선택한 영상·음원·이미지는 서버로 업로드되지 않으며, 이 브라우저에서 처리됩니다. 기본 소재를 불러올 때는 인터넷 연결이 사용될 수 있습니다.」 저장 위치(이 브라우저 IndexedDB) · 지우는 법 · 다시 열 때 원본을 다시 골라야 할 수 있다는 점도 같이 보여 줘요.
- 설계 · 기록: `docs/v4/`(REQUIREMENTS · CONTRACT · IMPL_LOG_{library,motion,audio,assets} · ASSETS · **TEST_RESULTS**).

## v3.5 새 기능 (2026-10-10, 0.6.0)

- **타임라인 확대 · 축소** — Ctrl/⌘+휠 · 트랙패드 두 손가락 벌리기는 마우스 자리 기준, `+`/`−` · 단추 · 슬라이더는 재생선 기준으로 확대해 보던 자리를 잃지 않아요. 최대 1초 = 600 px(1프레임 = 20 px), 최소는 전체가 한 화면. 0.1초 눈금, `Z` = 고른 것(없으면 구간)에 맞춰 확대 ↔ 이전 배율, 맨 아래 개요 막대(가운데 끌기 = 넘기기 · 양 끝 끌기 = 확대 · 두 번 누르기 = 맞추기), Shift+휠 = 가로로 넘기기.
- **타임라인 높이** — 줄 수에 맞춰 자동으로 늘어나고(최대 화면 절반), 넘치면 세로로 넘겨요. 줄 머리 · 눈금자는 고정. 위 가장자리를 두 번 누르면 다시 자동.
- **우클릭 메뉴** — 클립 · 자막 · 소리 · 화면 위 · 모자이크 · 마커 · 빈 줄 · 보관함 카드 · 미리보기 상자. `Shift+F10` · 길게 누르기 · 카드 「⋯」로도 열려요. 항목마다 단축키가 보여요.
- **보관함 카드** — 한 줄 카드(마우스를 올리면 「+」 타임라인에 추가 · 「⋯」 더보기), 한 화면에 더 많이.
- **재생** — `J`/`K`/`L` 빨리 보기(×2 · ×4, 보기용), 미리듣기 음량(출력 무관), 시간 칸을 눌러 시각 입력, `` ` `` 미리보기 크게, 「끝으로」 · 1프레임 단추, 재생 막대는 「16:9 ▾」 · 「보기 ▾」 두 메뉴로 정리.
- **구간 편집** — 타임라인에서 `I`/`O` 로 구간을 정해 「빼기」(`⇧Delete`, 연결된 자막 · 소리 함께 당김) · 「이것만 남기기」 · 구간만 듣기 · 구간 반복. `X` = 재생선 아래 클립을 구간으로, `Q`/`W` = 재생 위치까지 앞 · 뒤 자르기.
- **속성 칸** — 자막 4분류(글 · 모양 · 프리셋 · 움직임, 배치 방식 · AI 보이스 · 더빙은 「글」 아래), 소리 2분류, 클립 「전환」에서 앞 · 뒤 경계를 함께. 「읽을 문장」은 다를 때만 펼침.
- **바뀐 키** — 배치 방식(영상에 연결 ↔ 시간에 고정)은 `L` → `⇧P`. `K` 는 재생 중엔 멈춤, 멈춰 있을 땐 키프레임 넣기.
- 좁은 창(1024 ~ 1180 px)에서 칸이 겹치던 문제, 내보내기 중 이름 줄바꿈, 토스트가 영상을 가리던 문제를 고쳤어요. 설계 · 기록: `docs/v3.5/`.

## v3 새 기능 (2026-10-09)

- **연결 편집** — 자막 · 레이어 · 효과음 · 녹음/AI 음성 · 마커마다 「영상에 연결 / 시간에 고정」. 순서를 바꾸면 연결 요소가 함께 움직이고, 고정한 배경음악은 그대로예요. 나누기 · 무음 정리 뒤 위치를 다시 계산하고, 부모 영상을 지우기 전에 함께 지워질 요소를 보여 줘요(실행 취소 한 번).
- **빠른 탐색** — 보관함 썸네일 훑어보기(켜기/끄기), 원본 보기에서 `I`/`O`로 구간을 정해 그 구간만 넣기, 마커 `M`(이름 · 메모 · 목록), 스냅 `N`, 미리보기 중앙선 · 정렬 안내선.
- **스타일** — 색감 · 화면 변형(위치 · 크기 · 회전 · 불투명도 · 뒤집기 · 자르기) · 음량 골라 복사/붙여넣기(`Ctrl+C`/`Ctrl+V`/`Ctrl+Alt+V`, 여러 클립), 자막 일부 단어만 색 · 굵기 · 크기 · 밑줄 · 형광펜, 위치까지 담는 내 스타일, 프리셋 제목 · 설명 · 강조 · 브이로그.
- **프록시** — 「성능 우선 / 화질 우선」 미리보기. 사본은 필요할 때만 만들고(진행률 · 지우기), 내보내기는 언제나 원본으로 해요.
- **4K(2160p)** — 이 컴퓨터에서 짧게 실측해 가능할 때만 열려요. 예상 시간 · 용량을 보여 주고, 해상도를 몰래 낮추지 않아요.
- **화면 위(PIP · 겹치기)** — 영상 · 사진/로고 · 도형을 주 영상 위에 겹쳐요(위치 · 크기 · 회전 · 불투명도 · 자르기 · 앞뒤 · 잠금 · 숨김 · 표시 구간, PIP 소리 따로). v3.1: 타임라인 **「화면 위」 줄이 영상 줄 바로 위**(파이널컷의 연결 클립처럼 위 행 = 화면에서 앞, 블록에서 영상까지 연결 줄기), 보관함 카드를 줄에 **끌어 놓은 시각**에 올리기, 블록을 위아래로 끌어 앞뒤 바꾸기, 새 PIP 는 **오른쪽 아래 30 %**(사진은 오른쪽 위 25 %), 속성 칸 「PIP」 — 빠른 위치 9칸 · 꽉 채우기 · 크기 작게/보통/크게 · **테두리(색 · 두께) · 모서리 둥글기**(미리보기와 출력이 같은 식).
- **키프레임 · 가리기** — 위치 · 크기 · 불투명도 키(선형 · 부드럽게), 사진 확대 · 자막 등장/퇴장 프리셋, 모자이크 · 블러 · 단색 가리기 + 영역 키프레임.
- **소리 정리 · 녹음 · 더빙** — 대사 · 배경음악 · 효과음 · AI 보이스 · 내레이션을 역할별로(음량 · 음소거 · 미리 듣기용 솔로), 영상 소리 분리, 마이크 녹음 `R`(권한 · 입력 막대 · 카운트다운 · 재녹음), 자막 한 줄씩 더빙 `⇧R`.
- **AI 보이스(v3.2 — 창 하나)** — 머리 막대 「AI 보이스」(`⇧V`, 대본으로) 또는 `V` · 자막 패널(자막으로)로 여는 「AI 보이스 만들기」 창 하나에서 재료(대본 / 자막)만 고르고 **「만들어 넣기」 한 번**이면 만들고 → 바로 넣고 → 창을 닫아요(토스트 「되돌리기」). 들어 보고 넣고 싶으면 「먼저 들어 보기」 → 「타임라인에 넣기」, 단축키 `Ctrl+Enter`(⌘Enter). **Supertonic 3(OpenRAIL-M)** 모델을 이 기기에서 실행해요(처음 한 번 약 401 MB — 모델이 없으면 같은 창에서 동의 체크 하나 · 「받고 계속하기」, 다 받으면 다시 누르지 않아도 이어서 만들어 넣어요). 목소리는 **남성 1~5 · 여성 1~5**(「남성 1 — 낮고 차분한 톤」처럼 이름 + 설명, 기본 여성 3) — 공개 목소리를 섞어 만든 AI 음성이고 실제 사람 녹음 · 복제가 아니에요. 카드 ▶ · 「10개 이어 듣기」는 앱에 든 짧은 샘플(MP3)이라 모델을 받기 전에도 들을 수 있어요. 빠르기 · 품질 · 끝 고지 자막 · 짧은 자막 묶기는 「세부 설정」(접힘).
- **대본 탭** — 대본을 붙여 넣으면 문장(문장 끝 · 줄바꿈, 120자 넘으면 조각)으로 나누고 숫자 · 단위 · 약어 · 등식 읽기를 자동으로 고쳐요(화면 자막은 그대로, 「원래대로」로 되돌림). 문장마다 상태(만드는 중 · 완료 · 실패 이유)를 보고 듣기 · 다시 만들기 · 실패한 문장만 다시 · 전체 이어 듣기를 해요. 합성 결과의 앞뒤 무음은 다듬어(앞 0.05 · 뒤 0.10 초) 넣고, 재생 위치에 「자막 + 음성」(문장마다 자막을 실제 음성 길이로, 문장 사이 0.45초 · 문단 사이 0.9초) 또는 「음성만」(내레이션 한 항목)으로 넣어요. 같은 글 · 목소리 · 설정은 브라우저에 저장된 결과를 바로 써요(최대 300개 · 150 MB).
- **자막 탭 · 고치기** — 고른 자막(묶음)마다 예상 길이 / 자막 길이, 이미 음성이 있으면 「있음 → 교체」(이전 소리는 테이크에). 길이가 넘치면 「음성 길이 맞추기」 창에서 속도 · 문장은 「적용」 한 번에 바로 바꾸고(같은 씨앗), 「다시 만들기」(새 씨앗) 후보는 다 되면 한 번 자동으로 들려줘요. 자막 글이 바뀐 AI 음성은 프로젝트 「보이스」의 「변경된 음성 다시 만들기 (n)」 한 번으로 바로 바꿔요. WAV 내려받기 · MP4 합성, AI 생성 음성 고지 포함.
- **자동 저장 · 복구** — 이 브라우저(IndexedDB)에 자동 저장, 복구 가능한 프로젝트 목록, 자동 편집 전 복원 지점, `.moacut.zip` 백업(녹음 · AI 음성 포함), 외부망 없이도 받아 둔 글꼴 · 모델로 편집 · 음성 생성 · 출력.
- 설계 · 시험 기록: `docs/v3/`(BRIEF · DESIGN_V3_A/B · IMPL_LOG · **TEST_RESULTS**).

## 2. 사용법

1. **불러오기** — 「영상 불러오기」를 누르거나 창에 끌어 놓기 · `Ctrl+O` · 붙여 넣기. 여러 개를 고르면 고른 순서대로 타임라인에 이어 붙어요. 음악은 보관함의 「배경음악으로」 또는 배경음악 줄로 끌어 놓기.
2. **컷편집** — 타임라인 클립 가장자리를 끌어 앞뒤 자르기, `S`로 재생 위치에서 나누기, 끌어서 순서 바꾸기, `Delete`로 지우면 빈틈 없이 당겨져요. `Ctrl+D` 복제, `Ctrl+Z`/`Ctrl+Y` 실행 취소/다시 실행. 속성 칸에서 시작·끝 시각을 1프레임 단위로 고칠 수 있어요. 화면 비율 16:9 · 9:16 · 1:1, 「전체 보이기/화면 채우기」.
3. **자동 정리** — 「무음 정리」(`⇧S`): 기준 음량 · 최소 무음 길이 · 말소리 앞뒤 여유를 정하면 후보가 타임라인에 빗금으로 표시돼요. 후보마다 「지우기 전 듣기」「지운 뒤」로 들어 보고 체크한 것만 적용(한 번에 실행 취소). 「장면 나누기」(`⇧C`): 장면 점수를 분석해 민감도 · 최소 길이로 후보를 고르고 적용(나누기만, 지우지 않음).
4. **자막 · 색감** — `T` 또는 「자막 추가」로 직접 넣거나 「자동 자막」(`⇧A`)으로 받아쓰기(말소리 언어 한국어 · 영어 · 일본어 — 「자동」이면 말소리 조각마다 알아냄, 배경음만 있는 곳은 Silero 말소리 찾기로 건너뜀). 자막 번역(한국어 · English · 日本語 — 크롬 기기 안 번역, 언어 쌍마다 처음 한 번 「언어 팩 받기」)과 보이는 언어(원문 · 언어 하나 · 두 언어 함께) 고르기, SRT 언어별 내보내기 · 「언어별 모두 저장(ZIP)」(SRT + WebVTT). 「자막 표」(`⇧T`)에서 모든 자막과 번역을 한 표로 보고 바로 고치기, 찾아 바꾸기(`Ctrl+F`, 받아쓰기 오타를 한꺼번에 · 다음 자동 자막에도 기억) · 원문 바뀐 자막만 다시 번역, 읽기 속도 검사(한국어 10 · English 17 · 日本語 6 자/초 — 「빠름」 표시와 「끝 늘이기」). 글꼴(무료 한글 글꼴 30종 · 검색 · 분류 · 즐겨찾기 · 최근 · 미리보기 문구 · 굵기 · 내 TTF/OTF), 크기 · 색 · 외곽선 · 그림자 · 배경 상자 · 자간 · 행간 · 정렬 · 위치(9칸 또는 미리보기에서 끌기), 프리셋 4종(기본 대사 · 강조 · 브이로그 · 수업 설명), 스타일 저장 · 모든 자막에 적용, 합치기 · 나누기, SRT 불러오기 · 내보내기(SRT에는 글꼴 · 디자인이 저장되지 않음). 클립을 고르면 속성 칸 탭에서 음량(dB, 무음 ~ +12 dB) · 음소거 · 밝기 · 대비 · 채도 · 필터 8종 · 세기 · 원본으로.
5. **화면 전환 · 모자이크 · 안내선 · 리미터**
   - **화면 전환** — 타임라인 두 클립 사이 「+」 → 「화면 전환 넣기」를 고르거나 경계 가까이에서 `D`를 누르거나, 클립을 골라 속성 칸 「화면 전환」 타일에서 8종(겹쳐 넘기기 · 검정으로 · 흰색으로 · 왼쪽/오른쪽 닦기 · 왼쪽/오른쪽 밀기 · 원으로 열기)과 길이(짧은 클립 길이의 45 %까지)를 골라요. 전환만큼 두 클립이 겹쳐 전체 길이가 줄고, 소리도 같은 길이로 교차해요. 「모든 경계에 적용」「모두 없애기」.
   - **모자이크** — 재생 막대의 눈 가림 단추나 타임라인 「모자이크」(`B`)로 재생 위치에 상자를 넣어요. 모양은 **사각형 · 둥근 사각형 · 타원 · 정원 · 마름모**, 효과는 **블러 · 픽셀**, 세기 1~10 · 폭 · 높이 · 시작 · 끝. 미리보기에서 상자를 끌어 옮기고 오른쪽 아래 모서리로 크기를 바꿔요. 고른 상자 위 **도구 막대**에서 모양 바꾸기 · 따라가기 · **삭제**(휴지통, `Delete`, `Ctrl+Z`로 되돌림)를 바로 해요. 위치는 원본 영상 기준이라 컷을 자르거나 화면 비율을 바꿔도 같은 곳을 가려요.
   - **모자이크 따라가기(추적)** — 가릴 물체에 상자를 맞추고 「따라가기」(`⇧B`)를 누르면 그 장면부터 앞뒤로 물체를 찾아 **위치와 크기**를 기록해요(이 기기 안에서 계산, 1초에 15곳). 인물이 다가오면 모자이크도 같이 커지고, 멀어지면 작아져요(「크기도 따라가기」로 끄고 켜기, 배율 0.3~2.5×). 타임라인 모자이크 줄에 크기 변화가 옅은 면 그래프로, 놓친 구간은 빗금으로 보여요. 틀린 곳은 그 장면에서 상자를 끌어(위치) 또는 모서리를 끌어(크기) 고치면 그 시각 둘레 0.5초가 부드럽게 바뀌어요. 실행 취소 한 번으로 되돌려요.
   - **안내선** — 재생 막대의 「안내선」 단추(`;`)로 수평선 · 수직선 · 십자 · 격자(3 · 4 · 6 · 8칸)를 켜요. 선은 출력 화면 위에만 그려지고 화면 비율을 바꿔도 같은 비율 자리에 있어요. 수평 · 수직선은 끌어 옮기고 두 번 누르면 가운데로 돌아와요. 자막 · 모자이크 상자를 끌면 안내선 · 화면 가운데 · (켜져 있으면) 자막 안전 영역 테두리에 6px 안에서 붙어요(Shift를 누르고 끌면 안 붙음). 안내선은 이 브라우저의 화면 설정이라 프로젝트 · 실행 취소 · 내보내기에는 들어가지 않아요.
   - **리미터** — 아무것도 고르지 않은 속성 칸(프로젝트)에서 켜요. 프리셋 3종(말소리 또렷하게 · 음악까지 크게 · 터짐만 막기) 또는 게인 · 상한 · 회복 시간. 미리보기 재생에도 같은 계산이 적용되고, 얼마나 누르는지 미터로 보여요(파이널컷 리미터처럼 소리를 키우면서 상한을 넘지 않게).
6. **내보내기** — `Ctrl+E` → 해상도 타일(픽셀 크기 표시: 가로 854×480 / 1280×720 / 1920×1080, 세로 480×854 / 720×1280 / 1080×1920, 정사각 480 · 720 · 1080) → 「내보내기 시작」 한 번 → 끝나면 바로 내려받아요(MP4 · H.264 · AAC 48 kHz · 30 fps). 진행률은 ffmpeg가 알려 주는 실제 프레임 · 시각이에요. 실패하면 원인과 「같은 설정으로 다시 시도」「빠르게로 다시 시도」「720p로 바꿔 저장」을 보여 주고, **사용자가 고르기 전에는 해상도를 낮추지 않아요**.
7. **저장 · 복원** — 편집 내용은 이 브라우저 보관함에 자동 보관되고(머리 막대 「방금 보관함」), 첫 화면 「이어서 하기」에서 다시 열어요. 무음 정리 · 장면 나누기 · 자동 자막 교체 같은 큰 변경 전에는 복원 지점이 자동으로 생겨요(`Ctrl+Shift+S` = 수동, 「저장 ▾ → 복원 지점…」). 「저장」(`Ctrl+S`)은 `.moacut.json` 프로젝트 파일을, 「저장 ▾ → 백업 묶음 내려받기」는 녹음 · 음성 파일까지 담은 `.moacut.zip`을 내려받아요. 원본 영상은 (묶음에 넣기를 고르지 않으면) 들어 있지 않아서, 다시 열면 「원본 파일 다시 연결」 창에서 이름 · 크기로 자동 짝짓기(한꺼번에 고르기)하거나 하나씩 골라요.

- 도구 판(⇧S · ⇧C · ⇧A)은 하나만 열려요. 같은 키를 다시 누르면 닫히고, 다른 판으로 바꾸거나 닫으면 타임라인의 후보 표시(빗금 · 세로선)도 지워져요. 클립이 없으면 열리지 않고, 자동 자막을 만드는 중에는 닫히지 않아요(취소는 위 알약의 ✕).
- `D`는 재생 위치에서 가까운(2초, 그리고 화면에서 40px 안) 클립 경계에 겹쳐 넘기기 0.5초를 넣어요. 그 경계에 이미 전환이 있으면 덮어쓰지 않고 그 클립을 골라 전환 칸을 보여 줘요.
- 연결 편집: 자막 · 소리 · 마커는 기본으로 「영상에 연결」돼 클립과 함께 움직이고, `⇧P`(또는 속성 칸 「배치 방식」)로 「시간에 고정」으로 바꿀 수 있어요(v3.5 전에는 `L` — 지금 `L`은 빨리 보기). 클립을 지울 때 함께 지워질 연결 요소가 있으면 목록을 먼저 보여 주고, `Ctrl/⌘+Z` 한 번으로 모두 되돌려요.
- 원본 보기(`E`): 보관함 카드를 두 번 누르거나 고른 뒤 `E` → 미리보기 자리에 원본이 열려요. `I` · `O`로 쓸 구간을 정하고 `Enter`(타임라인 끝에 추가) 또는 `⇧Enter`(재생 위치에 삽입). 같은 `I` · `O`가 타임라인 화면에서는 타임라인 구간을 정해요(화면에 따라 다른 동작).
- 빨리 보기: `L`을 누를 때마다 ×1 → ×2 → ×4로 앞으로, `J`는 같은 단계로 뒤로(그림만 되감고 소리는 꺼요), `K`는 멈춤(멈춰 있을 때 `K`는 키프레임 넣기). 재생 단추 옆 속도 배지를 눌러도 바뀌어요. 보기용이라 출력엔 영향 없어요.
- 재생 막대: ⏮ 처음 · ◀| 1프레임 뒤 · ▶ 재생 · |▶ 1프레임 앞 · ⏭ 끝. 시간 칸을 누르면 `mm:ss.cc`(분:초.백분의 일 초)를 적어 `Enter`로 가고 `Esc`로 그만둬요. 「16:9 ▾」는 프로젝트 「화면」 탭과 같은 화면 비율, 「보기 ▾」에 맞춤 방식 · 자막 안전 영역(`G`) · 정렬 안내선 · 안내선(`;`) · 미리보기 가볍게 / 선명하게(출력 화질은 그대로)가 있어요. 스피커 단추는 미리듣기 음량 · 소리 끄기(이 브라우저에만 기억, 출력 · 역할 솔로와 별개), `` ` `` 또는 맨 오른쪽 단추는 보관함 · 속성 칸을 접어 미리보기를 크게 해요.
- 타임라인 구간: 타임라인 화면에서 `I` · `O`로 눈금자 위 분홍 괄호 구간을 정하고(`X` = 재생선 아래 클립을 구간으로, `⇧I` · `⇧O` = 그 지점으로, `⌥X`/`Alt+X` = 지우기), 재생 막대 위 구간 칩에서 **빼기**(`⇧Delete` — 구간을 지우고 뒤를 당겨요. 연결된 자막 · 소리 · 화면 위 · 마커도 함께 당겨지고, 구간 안에 완전히 든 연결 요소는 지워져요) · **이것만 남기기** · 구간 반복 · 구간만 듣기를 골라요. 실행 취소 한 번으로 돌아오고, 구간 자체는 저장 · 실행 취소 기록에 들어가지 않아요.
- `Q` · `W`: 재생 위치까지 앞 자르기 · 재생 위치부터 뒤 자르기(고른 클립, 없으면 재생선 아래 클립 — 클립 속성 칸 「여기까지 앞 자르기 · 여기부터 뒤 자르기」와 같아요).
- 마커: `M`으로 재생 위치에 마커를 넣고 바로 이름을 적어요(`Enter` 확정 · `Esc` 기본 이름). `[` · `]`로 이전 · 다음 마커, `⇧M`으로 프로젝트 패널의 마커 목록을 열고 닫아요.
- 스냅: 자막 · 소리 · 모자이크 블록이나 클립 끝을 끌면 8px 안의 클립 경계 · 재생 위치 · 마커 · 고정 요소 끝에 붙어요. `N`으로 끄고 켜고, 끌면서 `Alt`(맥 `⌥`)를 누르고 있으면 잠깐 안 붙어요.
- `B`는 모자이크예요. 다른 편집기의 블레이드(자르기)는 여기서 `S` 또는 `Ctrl/⌘+B`예요. `⇧B`는 모자이크 속성 칸이 보일 때(영상 위 모자이크 하나를 골랐을 때)만 동작해요.
- 메뉴(v3.5): 클립 · 자막 · 소리 · 화면 위 · 모자이크 · 마커 블록, 미리보기의 자막 · PIP · 모자이크 상자, 보관함 카드, 타임라인 빈 줄을 오른쪽 클릭하면(터치는 0.5초 길게 누르기, 키보드는 `⇧F10`) 그 자리 메뉴가 떠요. 항목은 단추 · 단축키와 같은 동작이고 옆에 단축키가 적혀 있어요. 고르지 않은 블록을 오른쪽 클릭하면 그것만 골라요. 보관함 카드는 마우스를 올리면 「+」(타임라인 끝에 추가 · 음악은 배경음악) · 「⋯」(같은 메뉴)가 보여요.

## 3. 구조

```
src/core       데이터 형식(types) · 편집 연산(ops) · 시간 계산(timeline) — 순수 함수
src/state      zustand 저장소(실행 취소 기록) · 원본 파일 보관(mediaRegistry) · 토스트
src/engine     ffmpeg(불러오기 확인 · 내보내기 · 미리보기 사본 · 장면 점수 · PCM), render(맞춤 · 색감 · 자막 그리기 · SRT), motion(모션그래픽 7종 · drawMotion — 미리보기 · 출력 같은 함수),
               fonts(글꼴 목록 · 불러오기 · 빠진 글자 검사), asr(Whisper 워커 · 후처리), analysis(음량 · 말소리 · 무음 · 장면), jobs(무거운 작업 1개씩)
src/player     미리보기 재생 엔진(WebGL 색감 + 캔버스 자막)
src/app        불러오기 · 저장 · 내보내기 · 자동 편집 흐름
src/ui         React 화면(자료실 화면 = src/ui/library · 모션 속성 = src/ui/motion)
src/library    자료실 목록 불러오기(catalog) · 검색(초성 · 동의어 · 거르기) · 즐겨찾기 · 출처 목록 · 소재 받기(libMedia)
public/library 기본 소재 파일 + 목록(index.json · catalog/*.json — 화면 코드와 분리)
tools/library  소재 만들기 · 가져오기 · 목록 채우기/검사(build-catalog)
docs           ARCHITECTURE(모듈 계약) · UI_SPEC(화면 명세) · FONTS(글꼴 라이선스) · DESIGN_BRIEF
tests          unit(코어) · e2e(실제 화면 조작 → 실제 MP4 검사) · pages(모듈 시험 페이지) · media(시험 미디어 + 정답 시각)
```

핵심 원칙:
- **비파괴 편집** — 프로젝트는 「원본의 어느 구간을 어떤 순서로」만 기억해요.
- **미리보기 = 출력** — 둘 다 같은 Project 값과 같은 함수(`placeClips` · `resolveSubtitles` · `fitRect` · `colorMath` · `subtitleRenderer`)를 써요. 자막은 같은 캔버스 그리기 함수로 미리보기에 그리고, 내보낼 때는 출력 해상도의 투명 PNG로 그려 ffmpeg가 합성해요. 그래서 고른 한글 글꼴 · 굵기가 그대로 영상에 들어가요.
- **자막은 원본 시각에 붙음** — 자막은 「어느 원본의 몇 초~몇 초」로 기억하고, 타임라인 시각은 클립 배치로 계산해요. 그래서 컷편집 · 무음 정리 · 순서 바꾸기 뒤에도 말소리에 맞춰 따라가요(원본 시각 ↔ 결과 타임라인 대응).
- **무거운 작업은 하나씩** — 내보내기 · 자동 자막 · 장면 분석은 동시에 돌지 않게 막아 메모리를 아껴요. 끝나면(성공 · 실패 · 취소 모두) 임시 파일을 지우고 ffmpeg 워커를 내려 메모리를 돌려줘요.

- **소리 없는 영상이 섞여도 출력** — 그 구간은 −120 dB 무음으로, 길이 그대로.
- **480p · 720p · 1080p 실제 크기** — 854×480 · 1280×720 · 1920×1080, 9:16 1080p 1080×1920, 1:1 480p 480×480. 모두 H.264 + AAC · 30/1 fps.
- **자막 위치 · 크기 비율 유지** — 세 해상도의 자막 상자(화면 비율 좌표) 차이 0.1 % 이하.
- **선택한 한글 글꼴이 영상에 적용** — G마켓 산스로 고른 자막 부분이 G마켓 그림과 차이 14.4, 프리텐다드 그림과 392.1(화소 12,395개 비교). 글꼴 30종 × 모든 굵기 65종을 불러와 한글 누락 0자(엔진 시험).
- **색감 · 음량 · 배경음악 반영** — 따뜻하게 + 밝기 +0.1이 R/B 비 · 밝기를 올림, 클립 음량 150 % → +3.51 dB(기대 +3.52), 배경음악이 소리 없는 구간에서 −29 dB로 들리고 페이드 인 · 아웃(처음 −50 dB, 끝 −57 dB).
- **한국어 자동 자막 생성 · 수정** — whisper-small(WASM): 글자 오류율 2.6 %, 문장 시작 · 끝 오차 0.05초 이내, 중복 없음, 진행 표시 23단계(내려받은 바이트 · 처리 구간). whisper-base(WebGPU): 오류율 11.8 %. 초안을 화면에서 고치고 나누기 · 합치기.
- **무음 컷 뒤 말의 앞뒤 보존 · 영상과 음성 일치** — 무음 후보가 정답 말소리 구간을 침범하지 않음, 문장 4개가 통째로 남음, 문장별 소리 어긋남 0~14 ms, 문장 가운데 프레임이 원본 프레임과 일치.
- **자동 컷 뒤 자막도 발화 시점과** — 결과 소리의 말소리 덩어리 대비 자막 시작 −0.06~−0.04초, 끝 +0.21~+0.25초(무음 여유 0.2초만큼).
- **자동 편집 전체 실행 취소** — 무음 정리(1개 → 4조각)도, 장면 나누기(1개 → 4개)도 `Ctrl+Z` 한 번에 원래대로.
- **유료 API 요청 · 사용자 미디어 업로드 없음** — 모든 시험에서 GET 이외 요청 0건, 바깥 호스트는 cdn.jsdelivr.net · hangeul.pstatic.net · huggingface.co · us.aws.cdn.hf.co(모델 파일)뿐.
- **화면 전환 = 미리보기와 같은 결과** — 경계 「+」와 타일로 8종을 넣은 영상(9개 × 2.3초 − 8 × 1초 = 12.7초, 381프레임 정확)의 전환 처음 · 가운데 · 끝 프레임을, 같은 원본 프레임에 미리보기 셰이더를 돌린 결과와 비교해 평균 차이 0~3.67/255.
- **리미터** — 게인 +9 dB · 상한 −3 dBFS로 내보낸 소리의 최고점 −2.89 dBFS(AAC 여유), 전체 +4.82 dB, 같은 리미터 코드로 직접 계산한 값과 차이 −41 dB. 미리보기(오디오 워클릿)도 재생 중 3.1 dB 눌렀어요.
- **모자이크 = 미리보기와 같은 결과** — 사각 블러 · 원형 블러 · 사각 픽셀 · 원형 픽셀 4개를 넣은 영상의 프레임(0.6 · 1.0 · 1.5초)을 미리보기 셰이더 결과와 비교해 영역 평균 차이 0.48~1.78/255, 크게 다른 화소 0.1 % 이하. 4종 모두 원본 대비 실제로 가려짐(평균 변화 4.8~11.9).
- **모자이크 따라가기** — 무늬 상자가 곡선으로 움직이고 2.0초에 배경이 통째로 바뀌는 시험 영상에서 0.5초 장면 하나로 3.4초를 따라가 51곳 평균 오차 1.9 px · 최대 4.0 px(1280 기준), 놓친 곳 0. 내보낸 영상에서 0.8 · 1.6 · 2.6 · 3.6초 그 시각 상자 자리가 흐려지고(평균 변화 49~53) 먼 곳은 그대로(0.0). 계산 0.5초.
- **모양 5종 · 크기 따라가기 = 미리보기와 같은 결과** — 둥근 사각형 · 정원 · 마름모와 배율이 0.6→1.7→1.1로 바뀌며 화면 가장자리로 가는 모자이크를 내보내 0.5 · 1.4 · 2.6 · 3.6초 프레임을 미리보기 셰이더 결과와 비교해 평균 차이 0.47~1.92/255. 크기가 바뀌어도 흐림 영역은 고정(가장 큰 크기), 그 시점 모양 · 크기만 보이는 마스크를 프레임마다 맞춰 넣어요.
- **커지는 물체 따라가기** — 무늬 물체가 90→200 px로 커지며 움직이는 시험 영상에서 0.5초 장면 하나로 3.4초를 따라가 배율 최대 오차 3.2 %(끝 1.82× · 정답 1.88×) · 위치 평균 2.6 px, 놓친 곳 0. 내보낸 영상에서 0.8 · 2.0 · 3.5초 커진 물체 안쪽 고리까지 흐려지고(평균 변화 17~21) 먼 곳은 그대로(0.0).
- 그 밖에: 장면 후보가 실제 전환 2.0 · 4.5 · 7.0초와 일치, SRT 왕복 일치, 프로젝트 저장 → 새로 고침 → 원본 다시 연결 → 클립 · 자막 · 배경음악 그대로, 망가진 원본으로 1080p 실패 시 원인 + 재시도 안내 · 해상도 유지 · 내려받기 0건 → 「같은 설정으로 다시 시도」로 1080p 성공, `F1` · `Tab` 가둠 · `Esc`.
- 코드 검토(Opus 2갈래, 실제 실행으로 확인한 문제 20건)를 모두 고쳤어요: 재생 중 편집 시 끝 처리, 시각 입력칸 초점만으로 값이 바뀌던 문제, 자막이 얹힌 클립 전체 색이 틀어지던 문제(오버레이를 BT.709 YUV로 합성 — 자막 밖 색 차이 ≤ 4), 복제 클립 위 자막 위치, 작업별 취소, 다시 연결 시 정보 갱신, 장면 점수 재사용 등.
- 속도(이 Mac, 11.4초 영상): 480p 10.7초 · 720p 17.6초 · 1080p 31.6초(균형). 「빠르게」는 약 1.8배 빠르고 파일이 큼.

## 6. 아직 확인하지 못한 것

- **v3**: 실제 마이크 · 실제 목소리 녹음(시험은 크롬 가짜 장치 · 시험음), Chrome 밖 브라우저, AI 보이스 WebGPU 경로 밖 기기 메모리, 서버를 끈 채 서비스 워커만으로 시작, AI 음성이 든 1080p · 2160p 출력(시험은 480 · 720p), 컷 뒤 더빙 위치(단위 시험만), 1080p 이상 키프레임 화소 검사, 사양 낮은 실기에서 4K, 긴 영상에서 자동 자막 · AI 보이스 · 고해상도 출력을 함께 돌릴 때, 브라우저 데이터를 실제로 지운 뒤 백업 복구, 사람의 화면 · 사용성 검토. 중간 단계별 독립 검증(Opus)은 사용자 요청으로 생략하고 마지막 자동 검사 1회로 대신했어요.
- **Windows**의 Chrome · Edge(macOS Edge는 확인), Safari · Firefox, 휴대폰 · 터치 기기(375 · 900 폭 배치는 캡처로만 확인).
- **긴 영상**(수 분~수십 분)과 큰 파일(수 GB)의 메모리 · 시간. 단일 스레드 ffmpeg라 1080p는 실시간의 약 0.36배 속도예요.
- **실제 촬영 영상**: 휴대폰 가변 프레임(VFR), 아이폰 HEVC 실기, 소리 시작이 어긋난 파일, 비정방 화소(SAR) — 회전 메타데이터는 합성 파일로만 확인.
- **실제 교실 녹음**(잡음 · 음악 · 여러 사람)에서 자동 자막 정확도와 무음 정리 결과. 시험은 TTS 음성으로 했어요. whisper-large-v3-turbo(WebGPU 전용, 약 762 MB)는 내려받아 돌려 보지 않았어요.
- 미리보기 소리를 귀로 듣는 확인(재생 시간 흐름 · 클립 경계 넘기 · 화면 전환은 자동 시험으로 확인).
- 모자이크 추적은 **실제 촬영 영상**(사람 얼굴 · 번호판 · 빠른 움직임 · 가려짐 · 고개 돌림)으로는 시험하지 않았어요. 시험은 무늬 물체가 움직이며 커지는 합성 영상으로 했어요. 크기는 가로세로 비를 유지한 채 커지고 작아지며(돌아가거나 찌그러지는 모양은 못 따라감), 물체가 가려지거나 화면 밖으로 나갔다 들어오면 놓칠 수 있어요 — 놓친 구간 표시를 보고 손으로 고쳐 주세요.
- 의미를 이해해 하이라이트를 고르는 자동 편집은 범위 밖(후속 개발).
- **v4 자료실**: 기본 소리는 **귀로 들어 보지 않았어요**(길이 · 최고 · RMS · 반복 경계 숫자로만 확인 — Kenney 효과음 이름 「확인음」 · 「파워 업」 등은 파일 이름 기준이라 들어 보고 다듬을 여지가 있어요). 외부 곡에 목소리가 없는지는 페이지 설명 · 태그 기준. 모션그래픽 출력은 720p 만 화소 비교(1080p · 4K, 9:16 · 1:1 배치, 화살표 · 강조 · 카운트다운 · 이름표 출력 화소는 숫자로 안 잼 — 4K 전체 화면 색종이는 메모리를 많이 쓸 수 있음). 배경음 반복 이음매의 미리보기 소리(자리 바꿀 때 약 16 ms 어긋날 수 있음)는 귀로 안 들음(출력은 표본 단위로 확인), 녹음 · AI 음성 반복 · 2× · 4× 재생 중 반복 · 아주 긴 반복은 화면 시험 없음. 사용 구간 손잡이 마우스 끌기 · 확대 100/200 % 화면 · 출처 「복사」(클립보드), 배포 빌드에서 오프라인으로 자료실 열기, 사파리 · 파이어폭스 · 터치, 밝은 화면은 눈으로 안 봤어요.
- **v4 브라우저 제약**: 미리보기 ↔ 출력이 같은 그림인 건 **같은 브라우저 안**에서예요(Canvas 글꼴 측정이 브라우저마다 달라요). 출력 형식은 MP4(H.264 + AAC)만 — ffmpeg.wasm 으로 실제 MP4 를 만들기 때문에 브라우저 MP4 녹화 지원과 상관없이 같은 파일이 나와요. 기본 소재 첫 사용엔 인터넷이 필요해요(받은 뒤엔 오프라인 가능).
